R1!
en
conf t
host R1
int g 0/0
ip add 10.1.1.10 255.255.255.0
no shut
ip nat inside

int g0/1 
ip add 11.1.1.1 255.255.255.252
no shut
ip nat outside

ex
ip route 0.0.0.0 0.0.0.0 11.1.1.2

*Setup pool
ip nat pool NAT_POOL 100.1.1.1 100.1.1.2 netmask 255.255.255.0

*ACL
access-list 1 permit 10.1.1.0 0.0.0.255

*IP NAT Policy
ip nat inside source list 1 pool NAT_POOL 

do copy running-conf startup-conf
